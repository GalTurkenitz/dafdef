# דפדף — זמן מסך לא מקבלים, מרוויחים

אפליקציה שחוסמת אפליקציות ממכרות, והמשתמש מרוויח דקות מסך על ידי
פעולות שמשפרות אותו: קריאה, כושר, למידה, כתיבה, מדיטציה, מים,
צעדים ושינה. המשתמש בוחר את הנישות שלו, והסבב חוזר על עצמו כל היום —
משהושלם, מתחיל סבב חדש מיד.

**מקור האמת:** `brief-v2-multi-niche.md`, מעליו `changes-v3.md`, ומעליו
`changes-v4.md`. כל סטייה — לשאול לפני. המסמכים הקודמים ב-`archive/`.

## סטאק

Vanilla HTML/CSS/JS, אתר סטטי, בלי פריימוורקים ובלי build step.
שתי ספריות חיצוניות, שתיהן בגרסה נעוצה ונטענות רק כשצריך אותן:
epub.js (ייבוא EPUB) ו-MediaPipe tasks-vision (מודולי המצלמה).
פריסה: Netlify. **דמו חי: https://dafdef-demo.netlify.app**

## הרצה מקומית

ES modules דורשים שרת, והמצלמה דורשת HTTPS או localhost.

```bash
npx serve .
```

## בדיקות

```bash
node scripts/test-verify.mjs      # אימות קריאה
node scripts/test-logic.mjs       # בנק ורצף
node scripts/test-rotation.mjs    # מנוע הסבב ושערי הרווח
node scripts/test-background.mjs  # צעדים ושינה
node scripts/test-reps.mjs        # ספירת חזרות — הגדרת הסיום של סעיף ו7
node scripts/test-level.mjs       # אבני דרך וספי רמות
```

`test-reps.mjs` מזין גוף מדומה למנוע הספירה ומאמת שעשר שכיבות מלאות
נספרות כעשר, שחצאי-חזרות ורעידות אינן נספרות, ושאין ספירה כשחלק
מהגוף מחוץ לפריים. בלי זה כל שינוי בחיישן דורש לעמוד מול הטלפון.

## תוכן

```bash
node scripts/build-learning.mjs            # מאגר המילים ללמידה
node scripts/fetch-wikisource.mjs          # מקור הספרים הזמני
node scripts/fetch-benyehuda.mjs --probe   # בדיקת מפתח בן-יהודה
node scripts/fetch-benyehuda.mjs --limit 200
```

מפתח בן-יהודה נקרא מ-`~/.secrets/benyehuda.txt` ולעולם לא נכנס לקוד
הלקוח. הנפקה חינם ומיידית ב-https://benyehuda.org/api_keys/new

## הסרגל התחתון

ליגה · התקדמות · **בית** (מרכז) · סטטיסטיקה · מקום שמור.
העיגול המלא מסמן את העמוד הנוכחי, לא את הבית.

## מונים, נקודות ורמה (V4)

`lifetime` סופר כמה נעשה בכל נישה **מאז ההתחלה** ואינו מתאפס לעולם.
`xp` צובר נקודות: משימה 10 · שלב במסלול 12 · סבב מלא 20 · אבן דרך 100 ·
ניצחון שבועי בליגה 250. הרמה נגזרת מהנקודות: 100 לכל אחת מחמש הרמות
הראשונות, ומשם 500 לרמה.

**שניהם מתעדכנים בנקודה אחת בלבד** — `creditMinutes` ב-store.js, שהיא
גם נקודת הזיכוי היחידה לבנק. זה מה שמונע מונה בלי זיכוי או להפך.

## הליגה היא דמו (V4, סעיף 2.2)

ליגה אמיתית דורשת שרת וחשבונות, וזה נדחה לאחרי סבב השיווק. היום הכל
רץ מקומית עם חברים מדומים, אבל **כל הגישה לנתונים עוברת דרך
`js/logic/league.js` בלבד** — ה-UI לא נוגע ב-localStorage. כשתגיע שכבת
רשת, מחליפים את גוף הפונקציות שם ו-`league.html` לא משתנה.

## עקרונות שקל לשבור בטעות

- **אפס גלילה** בכל המסכים. שלושה חריגים מוגדרים: מסלול השלבים,
  שדה הכתיבה, והקורא שממילא מבוסס עמודים. הספרייה וההגדרות
  מדפדפות בעמודים במקום לגלול.
- **אפס אימוג'י**, למעט הלהבה בצ'יפ הרצף — חריג יחיד ומאושר,
  שנאכף בבדיקה האוטומטית.
- **שערי הרווח אינם ניתנים לעריכה** בהגדרות. הם נגזרים מהשאלון
  בלבד; מי שרוצה שערים אחרים עונה עליו שוב.
- **כל כניסה לבנק עוברת דרך `earnUnits`** ב-store.js.
- **המונים והנקודות מתעדכנים רק ב-`creditMinutes`.** כל עדכון במקום
  אחר יוצר מונה שלא תואם את הבנק.
- `no-store` על js/css/html ב-`netlify.toml`, ו-`boot.js` מכריח
  טעינה מחדש כשהגרסה במכשיר ישנה. ספארי באייפון מתעלם
  מ-`must-revalidate` ומגיש מודולים ישנים.

## פרטיות

מודולי המצלמה רצים במלואם על המכשיר. אין העלאה, אין הקלטה ואין

בכל מסך מצלמה.
