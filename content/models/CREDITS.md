# מודלים תלת-מימדיים — מקור ורישיון

שני הקבצים כאן נבנו מתוך מודלים חיצוניים בעזרת
`scripts/build-models.mjs`. הסקריפט מוריד את המקור, מקטין אותו
למידה שמתאימה לטלפון וכותב GLB. הריצו אותו מחדש כדי לשחזר.

## body.glb

**MakeHuman base mesh (hm08)**
<https://github.com/makehumancommunity/makehuman> ·
`makehuman/data/3dobjs/base.obj`

רישיון: **CC0 1.0** — נחלת הכלל. שוחרר במפורש בספטמבר 2020,
וההצהרה כתובה בראש קובץ המקור עצמו.

נלקחה קבוצת `body` בלבד. שאר 171 הקבוצות הן עזרי דוגמנות —
`helper-skirt`, `helper-tights`, `helper-hair`, שיניים, עיניים,
ו-`joint-*` שהן קוביות סימון למפרקים.

## brain.glb

**"Brain AS" מאת AgnieszkaStarostecka**
<https://commons.wikimedia.org/wiki/File:Brain_AS.stl>

רישיון: **CC BY 4.0** — שימוש מסחרי מותר בתנאי ייחוס.
**הייחוס הזה חייב להופיע בעמוד הקרדיטים של האפליקציה לפני
ההגשה לחנות.**

מודל אנטומי אמיתי: שתי המיספרות, גירי וסולסי, מוח קטן וגזע מוח.
3,057,120 משולשים במקור, 18 אלף אחרי ההקטנה.

מה נלקח מכל קובץ:

| קובץ | רשתות המקור |
|---|---|
| `lungs.glb` | חמש אונות: עליונה ותחתונה משמאל, עליונה־אמצעית־תחתונה מימין |
| `heart.glb` | חדר שמאלי וימני, עלייה שמאלית וימנית |
| `kidneys.glb` | `Kidneyl`, `Kidneyr` |
| `muscle-pec.glb` | חזה גדול — ראש בריחי, חזי־צלעי ובטני, שני הצדדים |
| `muscle-arm.glb` | דלתא בריחית + שלושת ראשי התלת־ראשי, שני הצדדים |
| `muscle-legs.glb` | ישר הירך, שלושת הרחבים, דו־ראשי הירך, חצי־גידי וחצי־קרומי |
| `decor-core.glb` | ישר הבטן (הקוביות), אלכסוני חיצוני, רחב גבי, טרפז יורד, מסור קדמי, ישבן גדול |
| `decor-arm.glb` | דו־ראשי הזרוע (שני ראשים) וזרועי |
| `decor-leg.glb` | תאומי השוק (שני ראשים) וסולית |
| `decor-organ.glb` | כבד, קיבה, לבלב, כיס מרה, שלפוחית שתן, קנה, בלוטת התריס |

שכבת ה-decor אינה מסומנת ואינה לחיצה — היא רקע אנטומי. אותו
רישיון חל גם עליה.

השחזור: `node scripts/build-organs.mjs --src <תיקיית FBX>`.

## למה לא CC0 למוח

חיפוש מוח ב-CC0 שאפשר להוריד בפועל לא הניב תוצאה:

* **NIH 3D** — המודל `3DPX-021161` הוא CC BY (לא CC0), ודלי
  ה-S3 שלו מחזיר 403 בלי כתובת חתומה.
* **Smithsonian Open Access** — דורש מפתח API.
* **Sketchfab** — ההורדה מאחורי חשבון.
* מודלים אחרים בוויקישיתוף הם CC BY-SA, ורכיב ה-ShareAlike
  אינו מתאים להטמעה באפליקציה קניינית.
